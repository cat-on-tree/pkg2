# 2. 核心概念

## 2.1 Knowledge Carriers

本研究不把论文、专利、临床试验、项目直接视为知识本身，而是视为知识载体：

```text
Paper / Patent / ClinicalTrial / Project = Knowledge Carriers
```

这些对象承载知识 evidence，但不是最终知识单元。

Carrier Graph 描述的是：

```text
evidence objects
biomedical entities
projects / funding context
carrier-carrier links
carrier-entity links
```

Carrier graph 中的边是原始 evidence / context relation，例如：

```text
paper mentions bioentity
patent linked to paper
paper linked to trial
paper linked to project
trial linked to project
```

---

## 2.2 Knowledge Unit

当前工程版本定义：

```text
Knowledge Unit = typed BioEntity pair
```

当前主版 pair types：

```text
chemical-disease
gene-disease
chemical-gene
```

重要解释规则：

```text
carrier co-mention evidence does not imply an asserted biomedical relation.
chemical-disease pair != treatment claim
gene-disease pair != causal claim
chemical-gene pair != target claim
```

KU 是从 carrier evidence 中抽象出的知识单元，是后续 temporal prediction 和 Knowledge Field 建模的基本节点。

---

## 2.3 Carrier graph 与 KU-KU graph

Carrier graph 是原始 evidence/object layer：

```text
paper
patent
trial
project
bioentity
```

KU-KU graph 是 knowledge-unit layer：

```text
node = Knowledge Unit
edge = two KUs share at least one entity
```

二者不是重复图，而是不同抽象层级：

| 图 | 节点 | 边 | 主要含义 |
|---|---|---|---|
| Carrier graph | paper / patent / trial / project / bioentity | 原始 typed evidence relations | evidence support / source exposure |
| KU-KU graph | Knowledge Unit | shared-entity derived adjacency | knowledge-neighborhood proximity / diffusion context |

Stage 06F/06G 结果显示：

```text
carrier structural signal:
  对 top-K tail discovery 很强

KU-KU diffusion signal:
  对 global discrimination 很强

combined:
  通常整体最好
```

因此，后续 Knowledge Field 模型应同时利用：

```text
focal KU temporal state
carrier source/exposure
KU-neighborhood diffusion
```

---

## 2.4 Knowledge Field

所有 KU 在某个 cutoff year 的状态共同构成 Knowledge Field：

```text
K(t) = {K_i(t)} for all KU_i
```

其中：

```text
K_i(t)
```

表示第 `i` 个 KU 在 cutoff year `t` 的 learned / observed state。

Knowledge Field 模型的目标是描述：

```text
1. focal KU 自身状态如何演化；
2. carrier graph source/exposure 如何注入外部驱动；
3. KU-KU neighborhood 如何产生 diffusion / spillover；
4. 这些因素如何共同预测未来 patent / trial / translation heat。
```

在当前 Stage 07 v0 中，Knowledge Field 主要作为：

```text
temporal snapshot graph prediction problem
```

来实现：

```text
features at cutoff t -> future 3-year heat / emergence
```

后续 DynamicRDS 需要进一步将其升级为：

```text
explicit graph dynamical system
```

即显式学习：

```text
u_i(t) -> u_i(t + Δt)
```

---

## 2.5 Knowledge state variable

DynamicRDS 中新增显式知识状态变量：

```text
u_i(t)
```

表示第 `i` 个 KU 在 cutoff year `t` 的知识场强度、转化潜势或 learned scalar field state。

第一版可以定义为：

```text
u_i(t) = StateEncoderθ(x_i(t))
```

其中：

```text
x_i(t) = focal KU local temporal state features
```

后续可以比较可观测状态定义：

```text
recent_3yr_paper_heat
history_translation_heat
history_patent_count + history_trial_count
learned scalar projection from local features
```

DynamicRDS 的关键是显式建模：

```text
u_i(t + Δt)
=
u_i(t)
+
Δt · physical_rhs_i(t)
```

而不是只学习一个静态 score。

## 7.1 Stage 06E：KU representation ablation

比较：

```text
ku_full
numeric_only
raw_counts_only
ku_schema_only
```

主要结论：

```text
1. KU temporal numeric features 是主要预测信号；
2. KU schema categorical features 单独预测力有限，但在 temporal features 之外有增量；
3. KU full representation 通常优于 raw count-like / numeric-only 变体；
4. KU abstraction 不只是简单 carrier count 聚合，而是形成了有预测价值的 temporal/schema representation。
```

对 Stage 07 的启发：

```text
Knowledge Field 模型必须保留 focal KU temporal state。
```

记为：

```text
x_i(t)
```

## 7.2 Stage 06F：Carrier graph structural readout baseline

比较：

```text
carrier_structural_only_500k
ku_full_500k
ku_plus_structural_500k
```

Carrier structural readout 是：

```text
原始 carrier graph
→ cutoff-safe carrier node structural statistics
→ pool 到 KU × cutoff_year
```

Feature examples：

```text
degree
weighted degree
unique neighbor count
edge-type diversity
neighbor type composition
paper / patent / trial / project / bioentity neighbor exposure
```

主要结论：

```text
1. KU full 在 primary translation 和 trial 的整体指标上明显优于 carrier structural only；
2. carrier structural only 在 patent 和部分 trial top-K 指标上很强；
3. KU + carrier structural 通常获得最强或接近最强表现；
4. KU abstraction 与 carrier graph structural exposure 是互补关系。
```

对 Stage 07 的启发：

```text
Knowledge Field 模型应包含 carrier graph source/exposure term。
```

记为：

```text

```

## 7.3 Stage 06G：KU-KU diffusion proxy baseline

Stage 06G 构造 KU-KU shared-entity graph：

```text
node = KU
edge = two KUs share at least one entity
```

边权：

```text
edge_weight = sum over shared entities 1 / log(1 + entity_degree)
```

当前参数：

```text
top_neighbors = 30
max_entity_degree = 500
```

Diffusion proxy features：

```text
neighbor recent 3yr paper / patent / trial / translation activity
neighbor historical patent / trial / translation fractions
neighbor growth
neighbor top10 recent activity
weighted mean / mean / max / sum
```

比较：

```text
diffusion_proxy_only_500k
ku_plus_diffusion_500k
ku_plus_structural_plus_diffusion_500k
```

运行状态：

| Representation | Feature count | Metric rows | Error count | Runtime seconds |
|---|---:|---:|---:|---:|
| diffusion_proxy_only_500k | 55 | 72 | 0 | 497.8 |
| ku_plus_diffusion_500k | 116 | 72 | 0 | 827.8 |
| ku_plus_carrier_structural_plus_diffusion_500k | 163 | 72 | 0 | 1138.4 |

主要结论：

```text
1. diffusion proxy only 单独有明显 global prediction signal；
2. KU + diffusion 明显超过 KU full；
3. KU + structural + diffusion 通常获得最强 AUROC / AUPRC / Spearman；
4. carrier structural 仍然对 top-K discovery 有独立价值；
5. diffusion proxy 主要提升 global discrimination；
6. carrier structural exposure 对 top-tail candidate discovery 仍然重要。
```

对 Stage 07 的启发：

```text
Knowledge Field 模型应包含 KU-neighborhood graph diffusion。
```

记为：

```text
D_i(t)
```

## 7.4 Stage 06 总体结论

Stage 06E / 06F / 06G 共同证明：

```text
1. focal KU temporal state 有预测价值；
2. carrier graph structural exposure 在 KU full 之外有独立信息；
3. KU-KU neighborhood diffusion state 在 KU full 和 carrier structural 之外继续提供增量；
4. diffusion proxy 主要提升 global discrimination；
5. carrier structural exposure 对 extreme top-K discovery 仍然有强信号；
6. 未来转化涌现更像是 local state + source exposure + neighborhood diffusion 的组合过程。
```

因此，后续 Stage 07 不应再重复完整的 tabular ML baseline grid，而应进入正式算法构建：

```text
Temporal Knowledge Field GNN
Reaction-Diffusion-Source Knowledge Field model
Dynamic Knowledge Field Dynamics model
```

```text

```

而是优先比较：

```text

```

```text
Knowledge Field evolves through local reaction, source injection, graph diffusion, and decay.
```

因此对比模型也应围绕：

```text
reaction-diffusion dynamics

```

展开。

---

## 10.2 RDGNN-style baseline

RDGNN-style baseline 用于表示现有 reaction-diffusion GNN 思路。

其目标是回答：

```text
我们的 RDS / DynamicRDS 是否优于通用 reaction-diffusion GNN？
```

推荐实现形式：

```text
node representation h_i
reaction term Rθ(h_i, x_i)
diffusion term Dψ(h_j - h_i, A_ij)
optional nonlinear update
readout to future heat
```

一个可实现的 RDGNN-style 离散形式：

```text
h_i^{l+1}
=
h_i^l
+
α_l Rθ(h_i^l, x_i(t))
+
β_l Σ_j A_ij · Φψ(h_j^l - h_i^l)
```

最终预测：

```text
ŷ_i(t) = Head(h_i^L)
```

其中：

```text
Rθ:
  reaction MLP

Φψ:
  diffusion message MLP

A_ij:
  KU-KU edge weight

L:
  number of reaction-diffusion layers
```

RDGNN-style baseline 特点：

```text
1. 有 reaction-diffusion 结构；
2. 使用 h_j - h_i 形式的 pairwise state difference；
3. 主要是 representation dynamics；
4. 不显式区分 carrier source / proxy / knowledge physical state u_i(t)；
5. 不显式包含 source injection 和 decay。
```

与我们的 DynamicRDS 区别：

```text
RDGNN-style:
  generic reaction-diffusion representation learning

DynamicRDS:
  knowledge-field-specific physical state evolution
  with explicit local reaction, carrier source, proxy, diffusion flux, and decay
```

推荐模型名：

```text
rdgnn_style
```

推荐首批输出目录：

```text
data/results/knowledge_field/temporal_gnn/local_source_proxy_rdgnn_style_v0_seed42/
```

## 10.3 GRAND-style baseline

GRAND-style baseline 用于表示 graph diffusion / neural PDE 类 GNN。

其目标是回答：

```text
简单 graph diffusion PDE-style smoothing 是否能达到 RDS / DynamicRDS 的效果？
```

推荐实现形式：

```text
dh / dτ = diffusion(h, A) + reaction(h)
```

离散化后：

```text
h^{l+1}
=
h^l
+
δ · [
    -L_A h^l
    +
    Rθ(h^l)
  ]
```

其中：

```text
L_A:
  normalized graph Laplacian or random-walk diffusion operator

δ:
  diffusion step size

Rθ:
  feature-wise nonlinear transform
```

简化实现可以采用：

```text
h_i^{l+1}
=
(1 - α) h_i^l
+
α Σ_j Ã_ij h_j^l
+
Rθ(h_i^l)
```

最终预测：

```text
ŷ_i(t) = Head(h_i^L)
```

GRAND-style baseline 特点：

```text
1. 强调 graph diffusion / PDE-style propagation；
2. 可作为通用 graph diffusion baseline；
3. 不显式建模 source injection；
4. 不显式建模 knowledge state u_i(t) 的 one-step evolution；
5. 不区分 reaction/source/proxy/decay 物理项。
```

推荐模型名：

```text
grand_style
```

推荐首批输出目录：


# 11. Stage 07F：Dynamic Reaction-Diffusion-Source Knowledge Field Dynamics

## 11.1 Stage 07F 目标

Stage 07F 的目标是把当前 RDS v0 从：

```text
physics-inspired static predictor
```

升级为：

```text
explicit knowledge field dynamical system
```

核心问题从：

```text
given x_i(t), predict future heat
```

变为：

```text
learn how knowledge state u_i(t) evolves into u_i(t + Δt)
```

因此，DynamicRDS 应显式定义：

```text
u_i(t)
```

作为 KU 的知识场状态变量。

---

## 11.2 DynamicRDS 核心公式

DynamicRDS 的核心形式为：

```text
u_i(t + Δt)
=
u_i(t)
+
Δt · [
    R_i(t)
  + S_i(t)
  + P_i(t)
  + D_i(t)
  - Λ_i(t)
]
```

其中：

```text
R_i(t): local reaction term
S_i(t): carrier source / exposure injection term
P_i(t): diffusion proxy / prior field term
D_i(t): KU-KU graph diffusion flux
Λ_i(t): decay / dissipation term
```

更具体地：

```text
R_i(t) = Rθ(u_i(t), x_i(t))
S_i(t) = Sφ(s_i(t))
P_i(t) = Pη(p_i(t))
D_i(t) = Σ_j κ_ij(t) · [u_j(t) - u_i(t)]
Λ_i(t) = λ_i(t) · u_i(t)
```

最终：

```text
ŷ_i(t) = Readout(u_i(t + Δt), Δu_i(t), context_i(t))
```

其中：

```text
Δu_i(t) = u_i(t + Δt) - u_i(t)
```

---

## 11.3 True diffusion flux

DynamicRDS 与当前 WeightedDiffusion / RDS v0 的关键区别是 diffusion term。

当前 weighted diffusion 更接近：

```text
Σ_j A_ij h_j
```

DynamicRDS 应使用物理扩散通量：

```text
D_i(t) = Σ_j κ_ij(t) · [u_j(t) - u_i(t)]
```

这表示：

```text
知识场强度从高状态 KU 向低状态 KU 传导；
传导强度由 edge conductance κ_ij 控制。
```

第一版可以使用固定 conductance：

```text
κ_ij = normalized edge_weight_ij
```

后续版本可以学习：

```text
κ_ij(t) = softplus(gψ(edge_weight_ij, h_i(t), h_j(t)))
```

---

## 11.4 Source and decay terms

DynamicRDS 必须显式包含 source term：

```text
S_i(t)
```

原因是 Stage 06F 和 Stage 07 v0 结果已经说明：

```text
carrier source / exposure 对 translation emergence 有独立贡献。
```

Source term 表示 carrier graph 对 KU 的外部注入：

```text
paper / patent / trial / project evidence exposure
carrier graph structural readout
source-side translational pressure
```

DynamicRDS 还应加入 decay term：

```text
Λ_i(t) = λ_i(t) · u_i(t)
```

原因是知识场不应只增长。很多 KU 会经历：

```text
attention decay
research cooling
translation failure
topic aging
```

第一版 decay 可以实现为：

```text
λ_i(t) = softplus(MLP_decay([u_i(t), x_i(t)]))
```

并约束：

```text
λ_i(t) >= 0
```

---

## 11.5 DynamicRDS v1 推荐形式

DynamicRDS v1 推荐采用稳定、可控的 Euler update：

```text
u_next_i
=
u_i
+
dt · clamp(
    reaction_i
  + source_i
  + proxy_i
  + diffusion_i
  - decay_i,
  min = -c,
  max = c
)
```

可选稳定化设计：

```text
1. dt learnable or fixed scalar
2. nonnegative source via softplus
3. nonnegative decay via softplus
4. diffusion conductance nonnegative
5. residual update
6. LayerNorm on hidden context, not necessarily on scalar u
7. optional clamp / tanh scaling for du
```

推荐第一版配置：

```text
dt = 1.0
fixed edge conductance from normalized edge_weight
reaction/source/proxy hidden_dim = 128
num_layers = 2
loss = smoothl1
monitor_metric = auprc
```

推荐模型名：

```text
dynamic_rds
```

推荐首批输出目录：

```text
data/results/knowledge_field/temporal_gnn/local_source_proxy_dynamic_rds_v0_seed42/
```

---

## 11.6 DynamicRDS 与当前 RDS v0 的区别

| 项 | RDS v0 | DynamicRDS |
|---|---|---|
| 模型性质 | physics-inspired static predictor | explicit graph dynamical system |
| 状态变量 | hidden representation h_i | explicit knowledge state u_i(t) |
| 时间演化 | implicit prediction | explicit u(t) -> u(t+Δt) |
| diffusion | neighbor representation aggregation | flux term Σ κ_ij(u_j-u_i) |
| source | source branch representation | source injection term S_i(t) |
| decay | absent / implicit | explicit decay Λ_i(t) |
| 物理解释 | reaction-source-diffusion inductive bias | knowledge field dynamics |
| 输出 | score_i(t) | u_next, Δu, score |

# 18. 路线定位总结

当前项目已经完成：

```text
1. carrier graph validation；
2. KU layer construction；
3. long-window KU temporal prediction benchmark；
4. KU-level baseline diagnostics；
5. carrier source/exposure signal validation；
6. KU-neighborhood diffusion signal validation；
7. Temporal Knowledge Field GNN baseline；
8. WeightedDiffusion and RDS v0 physics-inspired GNN。
```

当前最重要结论是：

```text
未来转化涌现不是单纯由 focal KU 自身历史决定，
也不是单纯由原始 graph topology 决定，
而是 local KU state + carrier source/exposure + KU-neighborhood diffusion 的组合过程。
```

当前 RDS v0 进一步证明：

```text
reaction + source + diffusion 的结构化物理归纳偏置
优于普通 MLP / GraphSAGE / weighted diffusion baseline。
```

但当前 RDS v0 仍然是：

```text
physics-inspired static predictor
```

下一阶段应升级为：

```text
DynamicRDS:
  explicit knowledge state u_i(t)
  true graph diffusion flux Σ κ_ij(u_j-u_i)
  source injection
  decay / dissipation
  Euler-style temporal update
```

因此，后续正式模型应从：

```text
source-driven diffusion over a KU field
```

进一步升级为：

```text
knowledge field physical dynamics
```

最终理论目标：

```text
Knowledge Field Model
=
Local Reaction
+ Carrier Source / Exposure Injection
+ KU-KU Graph Diffusion Flux
- Decay / Dissipation
```

即：

```text
u_i(t + Δt)
=
u_i(t)
+
Δt [
    reaction_i(t)
  + source_i(t)
  + diffusion_i(t)
  - decay_i(t)
]
```

当前下一步：

```text
Stage 07E: RDGNN-style and GRAND-style physics/PDE GNN baselines
Stage 07F: DynamicRDS explicit Knowledge Field Dynamics model
Stage 07G: Dynamic model comparison and reporting
```
