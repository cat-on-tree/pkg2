# 技术路线：基于 PKG 2.0 的 Knowledge Field 动态建模框架

更新日期：2026-07-02

---

## 0. 技术路线总览

本研究的核心目标是：

从 PKG 2.0 中构建领域化异构时序知识载体图，将论文、专利、临床试验、项目等对象视为 **knowledge carriers**，而不是知识本身；进一步从 carriers 中抽取真正被传播、积累和转化的知识对象，即 **Knowledge Units**；随后在正式长时间窗口上构造 KU-level temporal prediction dataset，最终用于知识转化预测、可解释动态建模和 Knowledge Field / reaction-diffusion-source 模型研究。

整体理论主线是：

```text
Carrier Graph
  -> Knowledge Unit Layer
  -> KU Temporal Modeling Dataset
  -> Long-window KU Temporal Prediction Dataset
  -> Temporal Baselines and Ablations
  -> Knowledge Field Reaction-Diffusion-Source Model
  -> Interpretable Knowledge Flow Analysis
```

当前工程阶段重新定义如下：

```text
Stage 01: Knowledge Carrier Graph construction
Stage 02: Carrier-level Patent-Paper link prediction dataset construction
Stage 03: Carrier-level Patent-Paper baseline validation
```

# 2. Stage 01：Knowledge Carrier Graph Construction

## 2.1 核心思想

传统方法通常把：

```text
Paper
Patent
ClinicalTrial
```

直接视为 knowledge nodes。

本研究的关键区别是：

```text
Paper / Patent / ClinicalTrial / Project = Knowledge Carriers
```

也就是说，论文、专利、临床试验、项目只是知识的承载容器，而不是知识本身。

## 2.2 Carrier Graph 定义

定义：

```text
G_C = (V_C, E_C, T)
```

其中：

```text
V_C = V_Paper
    ∪ V_Patent
    ∪ V_Trial
    ∪ V_Project
    ∪ V_Author
    ∪ V_Institution
    ∪ V_Journal
    ∪ V_BioEntity
```

边类型包括：

| 边类型 | 含义 |
| --- | --- |
| paper cites paper | 学术扩散 |
| patent cites paper | 科学到技术转移 |
| paper linked to trial | 基础到临床转化 |
| paper funded by project | 外部输入 |
| patent linked to project | 技术开发资金或项目支撑 |
| trial linked to project | 临床研究资金或项目支撑 |
| document mentions entity | carrier 到 Knowledge Unit 的映射基础 |

## 4.3 Knowledge Unit 定义

当前工程版本采用：

```text
Knowledge Unit = typed BioEntity pair
```

即：

```text
z = (entity_i, entity_j, pair_type)
```

当前主版 demo 数据集采用 translational / mechanistic pair types：

```text
chemical-disease
gene-disease
chemical-gene
```

当前不把 `disease-disease` 放入主版。原因是 disease-disease 共现混合了 comorbidity、complication、risk factor、subtype hierarchy、near-synonymy 和 background co-mention 等多种语义关系，不适合与 chemical-disease / gene-disease / chemical-gene 混在主版 translational KU layer 中。

重要解释规则：

```text
carrier co-mention evidence does not imply an asserted biomedical relation.
chemical-disease pair != treatment claim
gene-disease pair != causal claim
chemical-gene pair != target claim
```

## 4.4 Canonicalization 策略

当前已修复 pair canonicalization：

```text
1. 不同类型 pair 按 pair_types 指定方向归一；
2. 同类型 pair 按稳定 entity key 排序；
3. reversed pair duplicate 被消除；
4. KU id 在 canonicalized pair 上生成。
```

sanity check 结果：

```text

```

## 5.3 Cutoff-based temporal prediction setup

正式 temporal prediction 必须围绕 cutoff year：

```text
history = years <= cutoff_year
future = years > cutoff_year and <= forecast_end_year
```

例如：

```text
cutoff_year = 2017
history = years <= 2017
future = 2018-2025
```

输入特征只能来自：

```text
paper / patent / trial / project / entity / KU evidence <= cutoff_year
```

标签来自 cutoff 之后：

```text
future_patent_label = 1
if patent_count_cum at cutoff_year == 0
and patent_count_year in future window > 0

future_trial_label = 1
if trial_count_cum at cutoff_year == 0
and trial_count_year in future window > 0

future_translation_label = 1
if no patent/trial evidence before cutoff
and new patent or trial evidence appears after cutoff
```

# 7. Stage 07：Knowledge Field Reaction-Diffusion-Source Model

## 7.1 Knowledge State 和 Knowledge Field

Knowledge State 不应被当前阶段的人工 rule-based proxy score 固定定义。

更合理的定义是：

```text
K_z(t) = Encoder_θ(X_z(≤t), S_z, G_t)
```

其中：

```text
X_z(≤t): KU 的历史 temporal evidence
S_z: KU static covariates
G_t: time-dependent graph context
K_z(t): learned latent Knowledge State
```

所有 knowledge units 的 states 构成 Knowledge Field：

```text
K(t) = {K_z(t)}_{z ∈ Z}
```

即：

```text
K(t) ∈ R^{|Z| × d}
```

## 7.2 基础动力学方程

核心模型可写为：

```text
dK(t)/dt = -D L_t K(t) + R_θ(K(t), X(t)) + S_θ(t)
```

其中：

| 项 | 含义 |
| --- | --- |
| K(t) | learned Knowledge Field |
| L_t | time-dependent graph Laplacian |
| D | diffusion coefficient |
| -D L_t K(t) | knowledge diffusion |
| R_θ | reaction term，知识增长、衰减、竞争、融合 |
| S_θ(t) | source term，funding、重大项目、政策等外部输入 |

异构边类型扩散可写为：

```text
dK/dt = Σ_{r ∈ R} D_r L_r K + R_θ(K, X) + S_θ
```

每种关系类型 `r` 有自己的 diffusion coefficient `D_r`。

## 7.3 模型模块

```text
Module 1: State Encoder
  K_t = Encoder_θ(X_t, S_t, G_t)

Module 2: Diffusion Layer
  Diff_t = Σ_r D_r L_r K_t

Module 3: Reaction Network
  React_t = MLP_θ([K_t, X_t, ΔX_t])

Module 4: Source Network
  Source_t = MLP_φ(Project / funding / source features)

Module 5: Prediction Head
  ŷ_{z,t+τ} = Head(K_z(t+τ))
```

## 7.4 重要设计原则

```text
1. 不在 Stage 04F 单独训练 encoder；
2. encoder 应作为 Stage 06/07 模型内部模块；
3. encoder 的作用通过主任务 ablation 评估；
4. 解释性通过 attribution / ablation / counterfactual / path analysis 完成；
5. 不为了手工可解释性牺牲主任务预测性能。
```

# 8. 任务层：预测任务设计

## 8.1 主任务 1：Clinical Translation Prediction

预测某个 KU 是否会在未来 `τ` 年进入 clinical trial：

```text
P(y_z^trial(t+τ) = 1)
```

```text
P(y_z^patent(t+τ) = 1)
```

## 8.3 主任务 3：Future Translation Emergence

预测某个 KU 是否会从 paper-only / pre-translation 状态进入 patent 或 trial evidence：

```text
P(y_z^translation(t+τ) = 1)
```

## 8.4 主任务 4：Time-to-Translation Prediction

预测从基础论文 evidence 到临床试验 / 专利 evidence 的时间：

```text
τ_hat_z
```
