# 2. 当前算法路线更新

## 2.1 Knowledge Field 模型定义

所有 KU 在某个 cutoff year 的状态共同构成 Knowledge Field：

```text
K(t) = {K_i(t)} for all KU_i
```

DynamicRDS 中显式定义 KU knowledge state：

```text
u_i(t) ∈ R^d
```

其中：

```text
i = KU node
t = cutoff year
d = state_dim
```

该状态表示：

```text
第 i 个 KU 在 cutoff t 时刻的 learned latent translation potential / knowledge-field state。
```

需要注意：

```text
u_i(t) 是任务驱动学习到的 latent state，
不是经过独立预训练的 node embedding，
也不是生成式 decoder 的隐变量。
```

---

## 2.2 DynamicRDS 核心形式

DynamicRDS v2 使用 vector-state graph field dynamics：

```text
u_i(t + Δt)
=
u_i(t)
+
Δt · [
    R_i(t)
  + S_i(t)
  + P_i(t)
  + D_i(t)
  - Λ_i(t)
]
```

其中：

```text
R_i(t): local reaction term
S_i(t): carrier source / exposure injection term
P_i(t): diffusion proxy / prior field term
D_i(t): KU-KU graph diffusion flux
Λ_i(t): decay / dissipation term
```

具体形式：

```text
R_i(t) = Rθ(u_i(t), x_i(t))
S_i(t) = Sφ(s_i(t))
P_i(t) = Pη(p_i(t))
D_i(t) = Σ_j κ_ij(t) · [u_j(t) - u_i(t)]
Λ_i(t) = λ_i(t) · u_i(t)
```

最终预测：

```text
ŷ_i(t) = Readout(u_i(t), Δu_i(t), u_i(t + Δt), context_i(t))
```

其中：

```text
Δu_i(t) = u_i(t + Δt) - u_i(t)
```

---

## 2.3 DynamicRDS 与 PINN / Physics GNN 的定位

当前模型不应表述为严格 PINN。

更准确表述：

```text
DynamicRDS is a physics-inspired graph dynamical model,
not a strict physics-informed neural network.
```

原因：

```text
1. 训练 loss 中没有真实物理 PDE / ODE residual；
2. 没有真实物理边界条件或守恒律约束；
3. reaction / diffusion / source / decay 是结构化归纳偏置，而不是真实物理定律。
```

因此，中文表述应为：

```text
DynamicRDS 是一个反应-扩散启发的图神经动力学模型，
用于 KU 层面的未来转化候选排序。
```

英文表述建议：

```text
DynamicRDS is a reaction–diffusion-inspired graph neural dynamics model
for KU-level prospective translation candidate ranking.
```

---

## 2.4 Diffusion 项的核心解释

DynamicRDS 的 diffusion 项为：

```text
D_i(t) = Σ_j κ_ij(t) · [u_j(t) - u_i(t)]
```

该项不是普通 neighbor aggregation：

```text
Σ_j A_ij h_j
```

而是状态差驱动的 graph flux：

```text
neighbor state higher than focal state:
  positive incoming flux

neighbor state lower than focal state:
  smoothing / damping effect

same state:
  no net flux
```

其领域解释是：

```text
KU graph 上邻近知识单元的 latent translation potential
通过 shared-entity proximity 对当前 KU 产生知识场通量。
```

更严谨表述：

```text
图扩散项并不是新的数学扩散算子；
其贡献在于将 state-difference graph flux 显式用于 KU-level future translation candidate ranking，
并与 reaction、source、proxy 和 decay 项解耦，形成可解释、可消融的图动力学结构。
```

# 3. 当前主要实验结论

## 3.1 Stage 06 诊断实验结论

Stage 06E / 06F / 06G 已提供以下证据：

```text
1. focal KU temporal state 有预测价值；
2. KU schema 在 temporal features 之外提供增量；
3. carrier graph structural/source exposure 对 top-K candidate ranking 有独立贡献；
4. KU-KU neighborhood diffusion proxy 提升 global discrimination；
5. future translation emergence 更像是 local state + source exposure + neighborhood diffusion 的组合过程。
```

因此 Stage 07 的模型设计不是任意堆叠 GNN，而是由 Stage 06 诊断结果驱动：

```text
local state      -> reaction term
carrier source   -> source injection term
diffusion proxy  -> proxy / prior term
KU-KU graph      -> diffusion flux term
temporal cooling -> decay term
```

---

## 3.2 Stage 07 单 seed 模型比较结论

当前已经完成模型包括：

```text
MLP no-graph baseline
GraphSAGE
WeightedDiffusion
Reaction-Diffusion-Source v0
RDGNN-style
GRAND-style
DynamicRDS
```

当前核心结论：

```text
1. GraphSAGE 明显优于 no-graph MLP，说明 KU-KU graph message passing 有增量价值。
2. WeightedDiffusion 和 GRAND-style 说明 graph diffusion 是强 baseline。
3. RDGNN-style 说明 generic reaction-diffusion GNN 有一定效果，但不一定充分。
4. DynamicRDS 通过显式 state variable、source/proxy injection、flux diffusion 和 decay，提供更可解释的 graph-field dynamics。
5. 单 seed 下 DynamicRDS 可达到较强 top-K candidate ranking，但 top-K 指标存在 seed sensitivity。
```

当前不应写：

```text
DynamicRDS 显著优于所有 baseline。
```

更稳妥写：

```text
DynamicRDS achieves competitive-to-strong top-K candidate ranking performance,
with additional mechanism-level interpretability.
```

---

## 3.3 DynamicRDS 消融结论

DynamicRDS 内部消融已经提供以下证据：

```text
1. no_diffusion 显著降低 top-K candidate ranking；
2. no_decay 降低稳定性和 top-K 表现；
3. no_source / no_proxy 影响模型的 source/proxy forcing；
4. full DynamicRDS 在 top-K ranking 上最强或接近最强。
```

该结果支持：

```text
diffusion flux 和 decay 是 DynamicRDS 的核心机制项，
但仍需在 multi-seed baseline comparison 中谨慎表述整体优势。
```

---

## 3.4 分层评价结论

已经完成或规划完成以下分层分析：

```text
1. history paper count strata
2. recent activity strata
3. source_score_quantile
4. proxy_score_quantile
5. pair_type
```

当前主要结论：

```text
1. DynamicRDS 不是简单 paper-count shortcut；
2. DynamicRDS 不是 simple recent-activity shortcut；
3. DynamicRDS top candidates 没有被 high-source / high-proxy KUs 垄断；
4. DynamicRDS 对 chemical-disease KUs 具有较强 relevance，符合 treatment-related translation candidate ranking 目标；

```

注意：

```text
这些分层分析支持 shortcut diagnostic，
但不应表述为证明了真实生物医学机制因果关系。
```

## 3.5 超参数敏感性与 tuned confirmation 结论

已经完成：

```text
one-factor hyperparameter sensitivity
tuned 5-seed confirmation grid
```

第一轮 one-factor sensitivity 发现：

```text
1. dropout=0.2 明显改善 top-K ranking；
2. lr=3e-4 明显优于 lr=1e-3；
3. state_dim 增大到 16/32 没有稳定收益；
4. 更深 num_layers 没有收益；
5. 更大 num_neighbors 没有稳定收益，甚至可能引入噪声；
6. global metrics 稳定，但 top-K metrics 对 seed / optimization 更敏感。
```

第二轮 tuned confirmation 固定：

```text
dropout = 0.2
lr = 3e-4
weight_decay = 1e-4
num_layers = 2
```

比较：

```text
state_dim ∈ {4, 8, 16}
num_neighbors ∈ {10/5, 15/10}
seed ∈ {1, 2, 3, 42, 2024}
```

最终推荐主配置：

```text
DynamicRDS tuned-main

state_dim = 8
num_layers = 2
num_neighbors = 15 10
dropout = 0.2
lr = 3e-4
weight_decay = 1e-4
```

5-seed 结果：

```text
AUPRC = 0.0476 ± 0.0009
AUROC = 0.7208 ± 0.0014
Spearman = 0.1022 ± 0.0006
P@1000 = 0.1148 ± 0.0120
NDCG@1000 = 0.1213 ± 0.0165
Enrich@1000 = 6.32 ± 0.66
```

更稳定但稍低的轻量配置：

```text
DynamicRDS stable-light

state_dim = 8
num_layers = 2
num_neighbors = 10 5
dropout = 0.2
lr = 3e-4
weight_decay = 1e-4
```

5-seed 结果：

```text
AUPRC = 0.0471 ± 0.0003
AUROC = 0.7217 ± 0.0007
Spearman = 0.1026 ± 0.0003
P@1000 = 0.1082 ± 0.0056
NDCG@1000 = 0.1124 ± 0.0065
Enrich@1000 = 5.96 ± 0.31
```

结论：

```text
DynamicRDS 的表现不依赖更高维 state 或更宽图传播；
更关键的是稳定优化和受控局部 graph flux。
```
